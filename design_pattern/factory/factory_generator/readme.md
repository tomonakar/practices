# factory generator pattern

ファクトリを生成するための２つの主要なアプローチを提供する設計パターン

1. 関数型アプローチ
2. 構造体アプローチ

## 関数型アプローチ
### 特徴
- 高階関数を使う
- 生成さらたファクトリは不変
- 関数として他の関数に渡しやすい
- よりGoらしいイディオマティックなアプローチ

## 構造体アプローチ
### 特徴
- 構造体を仕様してファクトリの状態を保持
- ファクトリの値を後から変更可能
- メソッドを通じてオブジェクトを生成
- より伝統的なOOPアプローチ

## 両アプローチの使い分け
- 関数型アプローチ：
  - 単純なファクトリーが必要な場合
  - イミュータブルな設定が望ましい場合
  - メモリ効率を重視する場合
- 構造体アプローチ：
  - 生成後にファクトリーの設定を変更したい場合
  - 追加の機能や状態が必要な場合
  - オブジェクト指向的な設計を好む場合
