# interface factory pattern

ファクトリ関数が具体的な構造体ではなく、インターフェースを返す

## 主な特徴と利点
1. カプセル化の強化
     - 実装の詳細（構造体のフィールド）を完全に隠蔽
     - ユーザーは定義さpreferenceたインターフェースのメソッドのみ利用可能
2. 実装の柔軟性
     - 条件に応じて異なる実装を返せる
     - クライアントコードを変更せずに実装を切り替え可能
3. テスト容易性
     - インターフェースを使用することで、モックオブジェクトの作成が容易
     - ユニットテストが書きやすい
4. 依存性の逆転：
     - クライアントコードは具体的な実装ではなく、抽象（インターフェース）に依存
     - コードの結合度を低く保てる
