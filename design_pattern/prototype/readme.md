# Prototype Pattern

## モチベーション
1. オブジェクトの生成コストを削減
   - プロトタイプパターンを使えば、既存オブジェクトのコピーをすることでオブジェクト生成のコストを抑えられる
2. 複雑なオブジェクトの生成を簡略化
   - プロトタイプを複製することで設定や構造が複雑なオブジェクトを簡単に作成できる
   - デフォルトの設定を持つオブジェクトを作成しそれをクローンして微調整することで、冗長な初期化コードを省略できる
3. 抽象的なインターフェースを提供
    - 例えば、オブジェクト生成時に`new`を直接使わずに、`colone()`を定義することで、サブクラスごとに異なる実装を持つオブジェクトを簡単に作成できる
    - ファクトリメソッドパターンや抽象ファクトリパターンと組み合わせて柔軟なオブジェクト生成が可能になる
4. 既存のオブジェクトを再利用
    - プロトタイプを一度作成すればそれを元にオブジェクトを生成できるため、オブジェクトの初期化状態を何度も設定する手間が省ける	
		- 例えば、ゲーム開発で「キャラクターのベースとなるオブジェクト」を定義して、それを複製することで、様々なバリエーションを簡単に作成できる
5. サブクラスの増加を防ぐ
    - 既存のオブジェクトをコピーして変更を加えることで新たなサブクラスを作らずに柔軟なオブジェクトを作成できる
