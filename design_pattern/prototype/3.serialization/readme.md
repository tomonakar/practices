# Serialization

1. 手動ディープコピーの課題
     - 入れ子となっているポインタ型の手動コピーの煩雑さ
2. シリアライゼーションによるディープコピー
     - `encoding/gob`を使うと、オブジェクトをバイナリデータに変換（エンコード）し、それを復元（デコード）することで新しいオブジェクトを作れる
     - シリアライザーはポインタを自動的にたどり、オブジェクトの状態を正しくコピーしてくれるため、手動の再起的なディープコピーを省略できる
3. Goでのシリアライゼーションによるディープコピーの実装
      - バッファを用意 `byte.Buffer`
      - エンコーダー`gob.NewEncoder`でオブジェクトをバッファにエンコード
			- デコーダ`gob.NewDecoder`を使って新しいオブジェクトにデータをデコード
      - 新しいオブジェクトを返すことでディープコピーが完了
4. シリアライゼーションによるディープピーのメリット
      - ポインタを持つ構造体やスライスのコピーが簡単になる
      - 再帰的なディープコピーの実装が不要
      - 複雑なオブジェクト構造でもエンコーダが自動で処理してくれる
5. プロトタイプデザインパターン
			- **既存オブジェクトをコピーし必要な部分だけ変更する**という考え方
			- `DeepCopy`を使って新しいオブジェクトを作り、それをカスタマイズすることで、オブジェクトの雛形（プロトタイプ）が活用できる
